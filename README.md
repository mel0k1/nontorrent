# NonTorrent

**Торрент-клиент, который проверяет за тебя.**

Качает быстро. Проверяет на вирусы **во время** скачивания и **после** установки —
прежде, чем ты успеешь что-то запустить.

## Почему NonTorrent

Обычные торрент-клиенты качают что угодно и ни за что не отвечают. Ты открываешь
раздачу «Photoshop 2026, активатор в комплекте», ждёшь два часа, а потом
двухчасовой ожидания оказываются подарком для трояна.

NonTorrent устроен иначе: **безопасность встроена в процесс скачивания**, а не
прикручена после. Как только файл внутри раздачи дописался до полного размера —
он уже идёт через конвейер проверки. Вердикт виден прямо в списке загрузок, а
угрозы изолируются в карантин автоматически.

| | Обычные клиенты | NonTorrent |
|---|---|---|
| Проверка на вирусы | нет / сторонний антивирус | встроенный конвейер: хэш → эвристика → YARA → clamd → VirusTotal |
| Во время скачивания | нет | да, по мере готовности файлов |
| После скачивания | нет | полный скан каталога раздачи |
| Угрозы | ждут твоей ошибки | авто-карантин + журнал с вердиктами |
| Трей и автозапуск | не всегда | трей + пауза всех из меню; автозапуск — только вручную в настройках |
| Дизайн | 2007 | тёмный «графит», shadcn/ui |
| Мусор в пакете | рекламы, тулбары, офферы | ничего: Rust-бинарь + веб-интерфейс |

## Возможности

- **Движок librqbit 9** — BitTorrent v1/v2/hybrid, DHT, uTP, magnet-ссылки
- **Инкрементальное сканирование** — каждый готовый файл проверяется ещё до конца раздачи
- **Полный скан после завершения** — весь каталог раздачи, повторно
- **YARA-сигнатуры** — встроенные правила (дропперы, эксплойты .lnk, упаковщики) + свои файлы из `yara_rules/`; работают без интернета
- **Дисковый кэш вердиктов VT** — ответы VirusTotal переживают перезапуски (TTL 21 день, «неизвестный файл» — 3 дня)
- **Системный трей** — открытие окна кликом, пауза/продолжение всех раздач из меню, выход; закрытие окна сворачивает в трей
- **Автозапуск ОС** — по умолчанию отключён, включается только в настройках
- **Планировщик скорости** — почасовые лимиты скачивания/отдачи по расписанию (окна через полночь, «0» = блокировка), нативные рейт-лимиты librqbit
- **Карантин** — угрозы изолируются в отдельную папку с сохранением метаданных
- **Журнал проверок** — вердикт, SHA-256, сработавшие движки, обнаружения
- **Обновления из приложения** — проверка GitHub Releases, скачивание с прогрессом и авто-запуск установщика
- **Пауза/продолжение/удаление с файлами**, открытие папки, поиск, лимиты скорости
- **Персистентность** — раздачи и настройки переживают перезапуск; повторный запуск поднимает уже открытое окно (single instance)

## Конвейер безопасности

Каждый файл проходит до шести ступеней:

```
┌────────────┐   ┌────────────┐   ┌────────────┐   ┌────────────┐   ┌─────────────┐   ┌───────────┐
│  SHA-256   │ → │ Эвристика  │ → │    YARA    │ → │   clamd    │ → │ VirusTotal  │ → │ Карантин  │
│ отпечаток, │   │ MZ-маскир.,│   │ сигнатуры  │   │сигнатуры   │   │ 70+ движков │   │изоляция   │
│ кэш на диск│   │энтропия>7.9│   │(в бинаре + │   │(опционально)│   │(опционально)│   │угроз      │
│            │   │            │   │  свои)     │   │            │   │             │   │           │
└────────────┘   └────────────┘   └────────────┘   └────────────┘   └─────────────┘   └───────────┘
```

- **SHA-256** — точная идентификация и кэш вердиктов; файл не проверяется дважды,
  кэш лежит на диске (`vt_cache.json`) и работает между запусками
- **Эвристика** — исполняемые форматы, двойные расширения, PE/MZ-сигнатура
  внутри «не-исполняемых» файлов, упаковщики по энтропии (>7.9)
- **YARA** — локальные сигнатуры на движке yara-x (VirusTotal): встроенные правила
  против дропперов, эксплойтов ярлыков и упаковщиков + пользовательские файлы
  из `appdata/yara_rules/*.yar`. Совпадения с `severity = high` дают вердикт «угроза»
- **clamd** — если указан адрес локального ClamAV-демона, файл уходит на полную
  сигнатурную проверку по протоколу INSTREAM
- **VirusTotal** — отпечаток сверяется с 70+ движками. Файл **не загружается** —
  уходит только хэш. В приложении есть встроенный ключ (хранится обфусцированным,
  можно отключить в настройках); свой бесплатный ключ или переменная
  `NT_VT_API_TOKEN` имеют приоритет. 4 запроса/мин — движок выдерживает лимит
  и кэширует ответы на диск
- **Карантин** — файл с вердиктом «угроза» изолируется в `<appdata>/quarantine`
  рядом с meta-файлом о происхождении

Подробнее: [docs/SECURITY.md](docs/SECURITY.md)

## Сборка из исходников

Нужны: **Node.js 20+**, **Rust 1.77+** и системные зависимости Tauri
([инструкция](https://tauri.app/start/prerequisites/) — на Linux это
`libwebkit2gtk-4.1-dev` и компания).

```bash
git clone https://github.com/mel0k1/nontorrent.git
cd nontorrent
npm install

# dev-режим с горячей перезагрузкой
npm run tauri dev

# релизная сборка (installers для твоей ОС в src-tauri/target/release/bundle)
npm run tauri build
```

Интерфейс можно посмотреть и без Rust — в браузере работает демо-движок
с мок-раздачами и живым журналом сканера:

```bash
npm install && npm run dev   # http://localhost:1420
```

## CI и релизы

GitHub Actions собирает приложение на каждый пуш в main: **Windows**
(NSIS-установщик `*-setup.exe`) и **Linux** (`.AppImage` + `.deb`). Артефакты
доступны во вкладке Actions. Публикация в **Releases** — автоматическая по
тегу:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Установленные клиенты сами замечают новый релиз: кнопка «Проверить
обновления» в настройках скачивает установщик с прогрессом и запускает
его (Windows — NSIS, Linux — AppImage/.deb в файловом менеджере).

## Настройка

Всё опционально и делается во вкладке «Настройки»:

| Параметр | Зачем |
|---|---|
| Сворачивать в трей | закрытие окна не завершает раздачи; выход — из меню трея |
| Автозапуск ОС | регистрирует NonTorrent в автозагрузке. По умолчанию **отключён** |
| Адрес clamd | `127.0.0.1:3310` — включить сигнатурный движок ClamAV |
| YARA-сигнатуры | локальные правила; свои `.yar` кладутся в `appdata/yara_rules/` |
| Планировщик скорости | правила «дни + время + лимиты»; применяется автоматически |
| Встроенный ключ VirusTotal | зашит в бинарник в обфусцированном виде (XOR), отключается одним тумблером |
| Свой ключ VirusTotal API | бесплатный ключ с virustotal.com — вердикты 70+ движков; приоритетнее встроенного |
| Карантин угроз | авто-изоляция файлов с вердиктом «угроза» |
| Скан во время скачивания | проверять файлы до окончания раздачи |

## Архитектура

```
┌───────────── Frontend: React 19 + shadcn/ui (src/) ─────────────┐
│  Загрузки · Безопасность · Настройки      [демо-режим в браузере]│
└───────────────▲──────────────────────┬──────────────────────────┘
     события    │                      │   invoke (Tauri IPC)
┌───────────────┴──────────────────────▼──────────────────────────┐
│                    Core: Rust · Tauri 2 (src-tauri/)             │
│                                                                  │
│  engine.rs    librqbit-сессия, поллер готовых файлов, DTO        │
│  scanner.rs   конвейер: хэш → эвристика → YARA → clamd → VT      │
│  yara.rs      YARA-движок (yara-x) + встроенные правила          │
│  vt_cache.rs  дисковый кэш вердиктов VT (TTL, между запусками)   │
│  scheduler.rs планировщик скорости → ratelimits librqbit         │
│  tray.rs      системный трей: окно, пауза всех, выход            │
│  vt.rs        встроенный VT-ключ (XOR-обфускация) + приоритеты   │
│  updates.rs   обновления: Releases API, скачивание, NSIS         │
│  settings.rs  настройки, персистентность раздач, карантин        │
│  commands.rs  17 IPC-команд (add/pause/resume/remove/scan/…)     │
└──────────────────────────────────────────────────────────────────┘
```
